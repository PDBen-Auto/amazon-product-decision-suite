## Amazon 商品判断ゲートウェイ

`amazon-product-decision-gateway`

最小限の根拠を別途運用される非公開判断エンジンへ送り、署名付き結果を検証します。公開クライアントにエンジン本体は含まれません。

スキルディレクトリ: `.`

**実装の根拠と依存関係**

Python 3.9+、cryptography、HTTPS サービス、環境変数のトークン、信頼できる Ed25519 公開鍵が必要です。運用・保持・料金は提供者が管理します。接続できなければローカル準備のみ行います。

**入力**

必須：decision_request JSON、商品、市場、通貨、根拠日。企業固有の GO には事業条件が必要です。送信先と送信範囲への個別許可が必要で、トークンをファイルに入れません。

**出力**

request_validation.json、許可後の decision_response.json と要約。要求・結果ハッシュ、署名、エンジン版を照合し、事実、モデル値、不足、条件を区別します。

[実行手順 · 制約と停止条件 · 依頼例](references/i18n/ja.md)

> 次のスキルを使用してください： `$amazon-product-decision-gateway` — 米国向けスマホホルダーの根拠要求を準備し、指定サービスへの送信許可後に検証済み結果を返します。日本語で回答し、根拠、不明点、操作権限を維持してください。

## 言語対応と検証

本書は目的、前提、入出力、手順、例、制約をまとめた日本語運用ガイドです。全参考資料の逐語訳ではありません。詳細技術資料、過去事例、スクリプトのエラー、サンプル画面、画像は原言語のままです。必要に応じて日本語で説明できます。構造・リンク・重要制約を確認していますが、各言語の母語話者による校閲は未実施です。
