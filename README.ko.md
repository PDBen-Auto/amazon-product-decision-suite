## Amazon 상품 의사결정 게이트웨이

`amazon-product-decision-gateway`

최소화한 근거를 별도로 운영되는 비공개 엔진에 전송하고 서명된 결과를 검증합니다. 공개 클라이언트에는 엔진이 없습니다.

스킬 디렉터리: `.`

**구현 근거와 의존성**

Python 3.9+, cryptography, HTTPS 서비스, 환경 변수 토큰, 신뢰할 수 있는 Ed25519 공개키가 필요합니다. 운영·보관·요금은 제공자 책임이며 서비스가 없으면 로컬 준비만 합니다.

**입력**

필수: decision_request JSON, 상품, 시장, 통화, 근거 날짜. 기업별 GO에는 사업 제약이 필요합니다. 구체적인 전송 대상·범위의 승인이 필요하며 토큰은 파일에 넣지 않습니다.

**출력**

request_validation.json, 승인 후 decision_response.json 및 요약. 요청/결과 해시, 서명, 엔진 버전을 확인하고 사실·모델값·공백·조건을 구분합니다.

[실행 절차 · 제약과 중단 조건 · 요청 예시](references/i18n/ko.md)

> 다음 스킬을 사용하세요: `$amazon-product-decision-gateway` — 미국용 휴대전화 거치대의 요청을 준비하고 지정 서비스 전송 승인 후 검증된 결과를 반환합니다. 한국어로 답하고 근거, 미확인 사항과 작업 권한을 유지하세요.

## 언어 지원과 검증

이 문서는 목적, 전제, 입출력, 절차, 예시와 제약을 다루는 한국어 운영 가이드이며 모든 참고 문서의 문장별 번역은 아닙니다. 상세 기술 자료, 과거 사례, 스크립트 오류, 예제 화면과 이미지는 원래 언어를 유지합니다. 요청 시 해당 언어로 설명할 수 있습니다. 구조, 링크와 핵심 제약을 확인했으나 각 언어 원어민 교정은 수행하지 않았습니다.

전달 전에 입력, 근거, 결측값, 출력 파일과 원래 완료 기준을 대조합니다. 실행하지 않은 단계는 미검증으로 표시하며 스크립트의 정상 종료를 업무 검증 성공으로 취급하지 않습니다.
