# Roadmap

## Near term

- Add more sanitized evidence-contract fixtures for market, VOC, supplier, and unit-economics handoffs.
- Improve local diagnostics for evidence conflicts, missing fields, and authorization scope.
- Publish a small set of synthetic end-to-end validation cases.

## Later

- Add versioned contract negotiation for private decision engines.
- Add reproducible response-verification fixtures and revocation guidance.

## Non-goals

- Publishing private prompts, weights, thresholds, customer data, or credentials.
- Guessing a proprietary Go/No-Go score when the private engine is unavailable.
- Presenting the Gateway as legal, compliance, procurement, or investment approval.
